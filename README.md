PROJECT: FITNOVA – Fitness & Wellness App

Act as a senior mobile application developer, UI/UX designer, product architect, and fitness technology expert.

IMPORTANT:
Do not create only static screens or a visual prototype. Build working navigation, functional buttons, authentication, data storage, workout tracking, progress charts, and notifications.
